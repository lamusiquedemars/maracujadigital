# AGENT — Reformulation du positionnement Maracuja Digital

## Mission

Reformuler le site `maracujadigital.fr`, en particulier la page d’accueil et la page `/site-web`, pour clarifier le nouveau positionnement commercial.

Maracuja Digital ne doit plus être présenté comme une agence qui installe ou configure WordPress. L’offre repose maintenant sur deux produits maison :

* `Maracuja Site` — Site vitrine sur mesure, simple et rapide :

	- Idéal pour des projets où l’autonomie est limitée (formule Essence).
	- Pages sur mesure, direction visuelle, formulaire de contact.
	- Maintenance légère, pas d’administration générale imposée.

* `Maracuja CMS` — Solution administrable maison (Laravel + Filament) :

	- Conçue pour des sites avec contenus vivants ou modules métier (formule Univers).
	- Interface ciblée : seuls les modules utiles sont exposés au client.
	- Modules activables selon le besoin : actualités, galerie administrable, catalogue, réservation.

L’objectif n’est pas forcément d’ajouter beaucoup de sections. Il faut surtout rendre les textes plus clairs, corriger les ambiguïtés, et aligner les pages avec cette nouvelle logique produit.

---

## Contexte général

Maracuja Digital propose des sites web pour artisans, indépendants, TPE, professions libérales, ateliers, musiciens, luthiers ou petites structures qui ont besoin d’un site professionnel, clair et maintenable.

La promesse n’est pas : “je vous installe un WordPress”.

La promesse est : “je construis le bon niveau d’outil pour votre activité”.

Il existe deux niveaux techniques/commerciaux :

### 1. Maracuja Site

`Maracuja Site` désigne les sites vitrines simples.

C’est adapté quand le client a besoin d’un site clair, bien structuré, rapide, mais pas forcément d’une administration complète.

Caractéristiques :

* pages sur mesure ;
* structure maîtrisée ;
* peu ou pas d’administration client ;
* formulaire de contact ;
* maintenance légère ;
* pas de CMS imposé si le besoin ne le justifie pas.

Positionnement à faire passer :

> Pas besoin d’un CMS lourd quand le site doit rester simple.

---

### 2. Maracuja CMS

`Maracuja CMS` désigne la solution administrable maison.

C’est une solution web administrable construite sur Laravel et Filament, avec une interface volontairement simple et des modules adaptés au métier du client.

Caractéristiques :

* administration claire ;
* modules activés selon le besoin ;
* contenus utiles administrables ;
* actualités, galerie, demandes, catalogue simple, agenda, réservation simple ou modules métier ;
* pas d’interface généraliste lourde ;
* pas de WordPress à maintenir côté client.

Positionnement à faire passer :

> Un CMS métier sur mesure, sans la complexité d’un CMS généraliste.

Attention : ne pas présenter Maracuja CMS comme une grosse plateforme SaaS ou un CMS universel concurrent de WordPress. Il faut le présenter comme une solution maison maîtrisée, utilisée pour créer des sites administrables simples et utiles.

---

## Offres commerciales

Les offres `Essence`, `Signature` et `Univers` restent valables.

Elles ne sont pas remplacées par `Maracuja Site` et `Maracuja CMS`.

Il faut distinguer :

* `Maracuja Site` / `Maracuja CMS` = produits ou solutions utilisés pour réaliser le site ;
* `Essence` / `Signature` / `Univers` = niveaux d’offre, de complexité, d’accompagnement et de prix.

### Essence

Essence correspond généralement à `Maracuja Site`.

À présenter comme :

* site vitrine simple ;
* présence professionnelle ;
* pages essentielles ;
* structure claire ;
* formulaire de contact ;
* pas d’administration inutile.

### Signature

Signature peut correspondre à `Maracuja Site` enrichi ou à `Maracuja CMS` léger.

À présenter comme :

* site plus complet ;
* identité plus travaillée ;
* contenus vivants possibles ;
* petite administration si utile ;
* actualités, galerie, contenus récurrents.

### Univers

Univers correspond clairement à `Maracuja CMS`.

À présenter comme :

* site administrable avancé ;
* modules métier ;
* catalogue simple ;
* demandes qualifiées ;
* agenda ou réservation ;
* parcours spécifique selon l’activité.

---

## Message central à faire passer

Le site doit faire comprendre ceci :

> Maracuja Digital ne vend pas un outil standard à paramétrer. Chaque projet reçoit le bon niveau de solution : un site vitrine simple quand cela suffit, ou un CMS métier sur mesure quand le client doit gérer des contenus et des modules.

Autre formulation possible :

> On ne met pas un CMS là où un site simple suffit. On ne livre pas un site figé là où le client a besoin d’un outil vivant.

---

## Ton éditorial

Le ton doit rester :

* clair ;
* concret ;
* professionnel ;
* sobre ;
* rassurant ;
* orienté client ;
* sans jargon inutile ;
* sans promesse exagérée.

Éviter les formulations trop abstraites ou marketing.

Éviter aussi les expressions vagues comme :

* “solution innovante” ;
* “expérience digitale complète” ;
* “plateforme sur mesure” ;
* “écosystème digital” ;
* “socle technique” ;
* “site nouvelle génération”.

Le mot `socle` est à éviter dans les textes commerciaux.

Supprimer ou fortement limiter :

* WordPress ;
* thème WordPress ;
* site WordPress ;
* installation WordPress ;
* solution hybride WordPress ;
* CMS généraliste comme solution principale.

WordPress peut éventuellement être mentionné une fois dans une phrase comparative, par exemple :

> Pas de WordPress à maintenir si le projet n’en a pas besoin.

Mais il ne doit plus apparaître comme une solution vendue dans les offres principales.

## Contraintes de modification

Ne pas faire une refonte visuelle complète sauf nécessité.

Priorité :

1. corriger les textes ;
2. clarifier les offres ;
3. supprimer les incohérences autour de WordPress ;
4. faire apparaître clairement Maracuja Site et Maracuja CMS ;
5. conserver l’esprit actuel du site.

Garder autant que possible :

* les classes CSS existantes ;
* la structure visuelle actuelle ;
* les composants existants ;
* les routes existantes ;
* les CTA existants s’ils restent cohérents.

Ne pas inventer :

* de prix nouveaux ;
* de modules non assumés ;
* de promesses techniques non présentes ;
* de clients ou références ;
* de garanties ;
* d’URL.
